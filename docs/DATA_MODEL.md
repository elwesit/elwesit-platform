# بنية البيانات

قاعدتا بيانات SQLite (وضع WAL) في مجلد البيانات (`WASIT_DATA_DIR`):

- **`main.db`**: كل البيانات الخاصة. المخطط في `server/migrations/001_init.sql` و`002_field_versions.sql`.
- **`public.db`**: ما نُشر فقط: جدول `listings` وجدول `site` (الإعدادات العامة والمناطق). المخطط في `public_001.sql`. يمكن حذفها في أي وقت وإعادة بنائها بإعادة النشر.

## مبادئ عامة

- كل سجل له معرّف UUID يولّده الجهاز، فيصبح الإنشاء بلا اتصال آمناً من التكرار.
- كل سجل يحمل `version` و`fv`. الحقل `fv` يحفظ لكل حقل رقم النسخة التي تغيّر فيها آخر مرة.
  - عند التعديل يرسل الجهاز `base_version`.
  - إذا تغيّر **الحقل نفسه** على جهاز آخر بعد ذلك، يرد الخادم 409 مع القيمة الحالية لتُعرض للمراجعة.
  - تعديل حقول مختلفة يُدمج تلقائياً.
- لا حذف نهائي من الواجهة. الأرشفة تتم عبر `archived_at`.
- التواريخ بصيغة ISO وبتوقيت UTC، وتوقيت نواكشوط هو UTC+0 دون توقيت صيفي. العرض والإدخال بتوقيت `Africa/Nouakchott`.
- المراجع المقروءة تكون `W0001` للعروض و`D0001` للطلبات، من جدول `counters`.

## المال

لكل مبلغ ثلاثة حقول:

- `*_raw`: النص كما ورد، مثل «3 مليون».
- `*_amount`: الرقم المفسَّر.
- `*_currency`: إحدى `MRU` (الجديدة) أو `MRO` (القديمة) أو `unknown`.

مع ذلك الحقل `*_basis`، وقيمه `total` أو `per_m2` أو `monthly` أو `yearly` أو `daily`.

قواعد المبالغ:

- `NULL` تعني «غير معروف»، و`0` تعني صفراً فعلاً.
- القيمة بعملة `unknown` لا تدخل المطابقة ولا تُنشر.
- التحويل: 1 أوقية جديدة = 10 أوقيات قديمة.

## الجغرافيا

- `wilayas` و`moughataas`: الولايات الـ15 والمقاطعات الـ63، مع الأسماء العربية والفرنسية والأسماء البديلة. المصدر مذكور في `server/geo/mauritania.js`.
- `areas`: الأحياء والمعالم. **لا تُملأ مسبقاً**؛ يضيفها المدير، ولا يُفترض انتماء حي إلى مقاطعة ما لم يحدده.
- `geometries`: حدود القطع. لكل حد طريقته (`manual` أو `imported`) ومصدره وترخيصه وتاريخه وحالة التحقق منه. يُنشر الحد فقط إذا كان مستورداً وموثّقاً ومرخّصاً.

## الجداول

| الجدول | المحتوى |
|---|---|
| `users`, `sessions`, `recovery_codes` | الحسابات، والجلسات (بصمة الرمز فقط)، ورموز الاستعادة (مشفّرة) |
| `settings` | إعدادات الموقع والتواصل والهوية (مفتاح/قيمة) |
| `people` | الأشخاص: أدوار متعددة، أولوية، مصدر، ملاحظات، `merged_into` عند الدمج اليدوي |
| `phones` | أرقام الشخص (عدة أرقام)، الرقم الموحّد `222XXXXXXXX`، واتساب أم لا |
| `properties` | العروض: الموقع، المخطط/القطاع/النمرة، المساحة، السعر بعملته، التوفر، آخر تحقق، الملاحظات الخاصة، إعدادات النشر `pub_*` |
| `property_sources` | مصادر العرض الواحد (المالك، وسطاء…)، ولكل مصدر سعره وشروطه وتاريخ تحققه. لا يرى مصدرٌ مصدراً آخر. |
| `requests` | الطلبات: العملية، الأنواع، المواقع (قائمة)، الميزانية بعملتها وأساسها، المساحة، الغرف، المرونة، الحالة |
| `sent_offers` | ما أُرسل لكل عميل من عروض، والقناة، ورده |
| `activities` | سجل التواصل (اتصال، واتساب، لقاء، معاينة، ملاحظة) |
| `tasks` | المتابعات والخطوة التالية مع موعدها |
| `appointments` | المعاينات والمواعيد، الأطراف، التذكير، النتيجة |
| `deals` | الفرص: المرحلة (اهتمام ← … ← تمت/توقفت)، سبب التوقف، المبلغ المتفق عليه |
| `commissions`, `commission_payments` | العمولة (مبلغ أو نسبة، والأساس، والطرف، وحصص الشركاء، والاستحقاق) ودفعاتها. **المحصَّل = مجموع الدفعات فقط.** |
| `files` | الصور والوثائق والتسجيلات (خاصة)، الترتيب، الغلاف |
| `inbox` | الوارد من الموقع وواتساب، و`client_token` لمنع التكرار، و`converted` لما نتج عنه |
| `captures` | الإضافات السريعة: النص الأصلي كما هو، والاستخراج، والنتيجة |
| `templates` | قوالب رسائل واتساب القابلة للتعديل |
| `dismissals` | تأجيل/إخفاء عناصر «اليوم» حتى وقت محدد |
| `client_ops` | نتائج العمليات حسب `x-op-id`، فإعادة الإرسال بعد انقطاع لا تنفذ العملية مرتين |
| `webhook_events` | معرّفات أحداث واتساب المستلمة (منع التكرار) |
| `audit_log` | سجل الدخول والنشر والدمج والتصدير والنسخ |

## `public.db`

`listings(ref, deal, type, title, description, wilaya/moughataa/area labels, area_m2, bedrooms, features, price_mru, price_text, loc_mode, lat, lng, radius_m, boundary, photos, cover, published_at, updated_at)`

يُكتب هذا الجدول فقط من `server/publish.js` عند النشر أو التحديث أو السحب. الإحداثيات فيه هي الإحداثيات **المعروضة**، أي التقريبية عند اختيار «تقريبي».
