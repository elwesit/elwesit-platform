# النسخ الاحتياطي والاستعادة والنقل

## ما تحتويه النسخة

ملف `.tar.gz` واحد يحتوي على:

- `main.db` و`public.db`، منسوختين بأمان أثناء التشغيل عبر SQLite backup API.
- مجلد `private/` (الصور الأصلية والوثائق والتسجيلات).
- مجلد `public-media/`.
- ملف `BACKUP.json`.

## إنشاء نسخة

- من الواجهة: الإعدادات ← البيانات ← «نسخة احتياطية كاملة» (يُنزَّل الملف).
- من الخادم: `npm run backup`، أو `npm run backup -- --out /path/file.tar.gz`. الافتراضي هو `DATA_DIR/backups/`.

مثال لنسخة يومية بـ cron، مع الاحتفاظ بآخر 14 نسخة:

```cron
30 2 * * * cd /opt/wasit && WASIT_DATA_DIR=/var/lib/wasit npm run -s backup && ls -1t /var/lib/wasit/backups/*.tar.gz | tail -n +15 | xargs -r rm
```

**انسخ الملفات خارج الخادم** (قرص آخر أو تخزين خارجي تملكه). النسخة على الخادم نفسه لا تحمي من تلف القرص.

النسخة تحتوي بيانات خاصة، فاحفظها مشفّرة إن أمكن. مثال: `gpg -c file.tar.gz`.

## الاستعادة

```bash
sudo systemctl stop wasit
WASIT_DATA_DIR=/var/lib/wasit npm run restore -- /path/wasit-backup-....tar.gz
sudo systemctl start wasit
```

ما يحدث أثناء الاستعادة:

- يُتحقق من سلامة قاعدة البيانات في النسخة (`integrity_check`) قبل أي تغيير.
- يُعاد تسمية مجلد البيانات الحالي إلى `<مجلد البيانات>.before-restore-<رقم الوقت>` بجانبه، فلا يُحذف شيء.
- لا تُستعاد الجلسات. يجب الدخول من جديد.

## النقل إلى خادم آخر

1. أنشئ نسخة على الخادم القديم.
2. ثبّت المنظومة على الخادم الجديد (انظر DEPLOY.md) دون إنشاء حساب.
3. استعد النسخة، ثم شغّل الخادم.
4. حدّث `BASE_URL` وDNS. الحسابات وكلمات المرور تنتقل مع النسخة.

## التصدير

- **Excel** (الإعدادات ← البيانات): أوراق العملاء والطلبات والعروض والمواعيد والصفقات والعمولات والمتابعات، بعناوين عربية ومن اليمين لليسار، مع تحييد الصيغ.
- **JSON**: كل الجداول، للنقل إلى نظام آخر.
