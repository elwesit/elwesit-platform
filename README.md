# الوسيط العقاري

منتج واحد بواجهتين على مصدر بيانات واحد:

- **الموقع العام** (`/`): عربي من اليمين لليسار، سريع، يعمل بلا جافاسكربت للبحث والنماذج، بحث بيع/إيجار/نوع/موقع/سعر، قائمة وخريطة، صفحة لكل عقار مع اتصال وواتساب ومشاركة، ونماذج «أبحث عن عقار» و«اعرض عقارك» و«مهتم بهذا العقار».
- **مساحة العمل** (`/admin/`): تطبيق ويب قابل للتثبيت (PWA) للمدير فقط: اليوم، الوارد، العروض، الطلبات، العملاء، المواعيد، الفرص والعمولات، الإضافة السريعة (كتابة/إملاء/لصق/صوت)، الإعدادات.

الفصل الأمني: الموقع العام يقرأ من قاعدة بيانات منفصلة (`public.db`) لا تحتوي إلا ما نُشر صراحةً، عبر اتصال للقراءة فقط. البيانات الخاصة في `main.db` لا يصل إليها إلا حساب يحمل صلاحية إدارة مُنحت من سطر الأوامر على الخادم.

## التشغيل السريع (للتجربة)

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run build                     # يبني واجهة الإدارة
npm run admin:create -- --email you@example.mr --name "اسمك"   # يسأل عن كلمة المرور بشكل مخفي ويطبع رموز الاستعادة
npm start                          # http://localhost:8080 و http://localhost:8080/admin/
```

احفظ رموز الاستعادة المطبوعة في مكان آمن: هي الطريقة الوحيدة لاستعادة كلمة المرور من الواجهة دون الوصول إلى الخادم.

## الأوامر

| الأمر | الغرض |
|---|---|
| `npm start` | تشغيل الخادم |
| `npm run dev` | تشغيل مع إعادة التحميل عند تعديل الخادم |
| `npm run build` | بناء واجهة الإدارة إلى `admin-ui/dist` |
| `npm test` | اختبارات الوحدة والخادم |
| `npm run test:e2e` | اختبارات المسارات الكاملة في Chromium (حاسوب وجوال) |
| `npm run admin:create -- --email E` | إنشاء حساب مدير |
| `npm run admin:reset -- --email E` | تغيير كلمة المرور من الخادم (يُبطل كل الجلسات) |
| `node server/cli.js set-role --email E --role none` | سحب الصلاحية فوراً |
| `npm run backup` | نسخة احتياطية كاملة |
| `npm run restore -- FILE` | استعادة نسخة (مع إبقاء البيانات الحالية جانباً) |

## بنية المجلدات

```
server/        الخادم (Express) — الواجهات، الصلاحيات، النشر، الصور، التصدير، النسخ، واتساب
server/migrations/  مخطط قواعد البيانات
server/geo/    الولايات والمقاطعات (المصدر مذكور في الملف)
shared/        منطق مشترك بين الخادم والواجهة: المحلل العربي، العملة، المطابقة، «اليوم»، البحث
admin-ui/      واجهة الإدارة (React + Vite، PWA)
public-static/ ملفات الموقع العام (CSS/JS/أيقونات)
tests/         unit/ (node --test) و e2e/ (Playwright)
```
